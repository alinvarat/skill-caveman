# caveman

Use only on an explicit caveman-mode request. Short grammatical replies; normal mode or stop caveman ends it.

This is an agent skill: `SKILL.md` tells an AI coding agent such as Claude Code when to use it and which steps to follow.

## Install

```bash
git clone https://github.com/alinvarat/skill-caveman.git ~/.claude/skills/caveman
```
